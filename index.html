Как устроено раздельное хранение конспектов + PDF и как легко обновлять сайт

Ниже — подробная инструкция по работе с HTML-конспектами, прикреплёнными PDF от преподавателей и публикацией на GitHub Pages.

1. Раздельное хранение HTML и PDF

В репозитории на GitHub файл index.html весит всего ~60 КБ — в нём хранятся только оболочка сайта и список карточек. Сами тексты конспектов лежат по отдельности в lectures/<id>.enc.json, а прикреплённые PDF преподавателей — в lectures/<id>.pdf.enc.json. Они подгружаются и расшифровываются в браузере только тогда, когда студент их открывает!

2. Ваши файлы на ноутбуке не трогаются

Ваши исходные HTML и PDF файлы в папках на компьютере (C:/Users/CTEII/Storage/HSF/...) никогда не изменяются и не шифруются. Браузер просто считывает копию выбранного файла и формирует зашифрованный пакет .enc.json для загрузки в GitHub.

🚀 Первичная настройка сайта на GitHub Pages (делается 1 раз за 5 минут)

  1. Создайте аккаунт и репозиторий: зайдите на github.com, нажмите «+» → New repository. Для ссылки без лишнего «хвоста» назовите репозиторий точно как ваш логин: ваш-логин.github.io (либо коротко, например fpm). Оставьте Public и нажмите Create repository.
  2. Распакуйте скачанный архив: распакуйте архив hse_fpm_github_kit.zip в отдельную папку на компьютере. Внутри будут лёгкий index.html и папка lectures/.
  3. Загрузите файлы на GitHub: нажмите uploading an existing file, перетащите туда index.html вместе с папкой lectures/ и нажмите Commit changes.
  4. Включите сайт: откройте Settings → Pages, в списке Branch выберите main и нажмите Save.
